# Languages

The integration's Home Assistant UI texts are translated into:

| Language | Code |
| --- | --- |
| English | `en` |
| German | `de` |
| Dutch | `nl` |
| Norwegian Bokmål | `nb` |
| Danish | `da` |
| Swedish | `sv` |
| French | `fr` |

The translation that is shown is **not** a per-entity setting. Home Assistant
uses the language of the user looking at the UI (or, for backend-composed
messages such as repair issues, the language configured for the system in
**Settings → System → General**). Change that language and the integration's
config flow, entity names, options, repair issues and error messages follow it
after a restart.

## Entity ids stay English

Home Assistant normally derives an entity id from the entity's name *in the
active language*. This integration pins the id to the English name instead, so a
German install still gets `sensor.xpeng_<vehicle>_battery` — not
`sensor.xpeng_<vehicle>_batterie`. Only the friendly name shown on the dashboard
is translated. Automations, blueprints and the examples in this documentation
are therefore identical in every language.

The VIN-based device name (`XPENG <last six VIN characters>`) is not
translated.

## What is still English

A few strings are generated by code rather than read from the translation files,
and stay in English for now:

* the option labels of the config-flow dropdowns (sign-in method, command
  preset, per-group permission states), and the capability-group names in the
  options form;
* free-form sensor states such as `Available: 1.2.3` or `Unknown (4)`;
* the select options for seat heating/ventilation and steering-wheel heating;
* the dashboard card, this documentation and the README.

## Fixing or adding a translation

Translation files live in
[`custom_components/xpeng/translations/`](https://github.com/xpengtoolkit/xpengtoolkit/tree/main/custom_components/xpeng/translations).
`en.json` is the source of truth; every other file must carry the same keys.
`docs/TRANSLATIONS.md` holds the rules, and

```bash
python3 tools/check_translations.py
```

checks key parity, placeholders, code blocks and URLs for every language.
Corrections are welcome as pull requests against the repository.
