# Tutorials

Step-by-step walkthroughs that take you from a freshly installed integration to
a finished result. They are longer than the [examples](../examples/overview),
which are small copy-paste snippets, and they explain one option at a time
rather than listing every possibility like the
[reference](../reference/options).

- **[Set up the XPENG Vehicle card](vehicle-card)** — enable the optional bundled
  dashboard card, add it to a dashboard, choose which car it shows, configure it
  for several cars or renamed entities, and keep it updated.
